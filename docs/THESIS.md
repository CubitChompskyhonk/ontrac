# OnTrac thesis

The system of oppression is often not a villain with a face.
It is a shrug: forms, holds, portals, phone trees —
easy if you can operate them, impossible if you cannot.

Cubit builds the other answer.
Not charity. Not a lecture. A button.

One finger.
Approve — do this for me.
The caseworker moves the machine until the loop closes.

User-delegated bureaucracy is a product failure.
Representation through consent is the core.
