# OnTrac pilot protocol (Kai · WD8)

## Half-measure fail conditions
- Primary CTA asks user to “call CRA yourself” / “email them yourself” with no system path
- Progress lost on app kill
- Consequential act without consent receipt
- CRA password requested by OnTrac

## Pass criteria (single session)
1. Complete onboarding + compliance gates
2. Create case
3. Capture ≥1 vault document (or demo path)
4. Record CRA guide outcomes
5. Name outreach recipient once → system letter → share intent
6. Optional: call outcome with ref
7. Export consent log

## Pilot cohort
3–5 users who struggle with calls/portals. Founder is support, not the caseworker for their homework.
